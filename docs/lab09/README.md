# Lab 09: Product Decisions (Team 03)

Full submission: [Team03_Lab09_ProductDecisions.pdf](Team03_Lab09_ProductDecisions.pdf)

## Result from LM2
6 of 8 students came back to the app on their own (our target was 6+).
So we **persevere**, but in small steps.

## Scope decisions

| Feature | Decision | Why |
|---|---|---|
| Event list | Keep | 7/8 students had missed events; 6/8 came back on their own. |
| Event details | Keep | Students check time and place before deciding. |
| Search, filters, soonest first | Keep | Students used them on their own in the trial. |
| "For you" ordering | Modify (keep simple) | 4/8 set their interests. It only sorts by interests and college. |
| Registration, seat counts, login | Defer | Only 2/8 registered. Not needed for the first journey. |
| Notifications | Drop | Students came back without reminders. |
| Ratings | Drop | Nobody asked for them. |

## User journey (LM3)
A student opens the app, sets their interests, searches or filters events,
and opens one to see the details. They can decide to go without checking
Instagram or Outlook.

## User stories
1. See upcoming events soonest first or "For you".
2. Search and filter events.
3. Open an event page with all key details.
